# Проба Godot 4.4 (не гра)

Перевірка рушія Godot для Regnum Land на телефоні й ПК: галявина-острів, герой (`hero-mobile.glb`),
20 нових 3D-попалів (кандидати з `models/pals/candidates/`, форма 1, кліпи idle/walk/attack/happy/blink),
джойстик і «Дія» для телефона, WASD/мишка для ПК, перемикач якості, лічильник FPS.
Гра в `site/` не змінюється й нічого звідси не бере.

Збірка під браузер: `GODOT=/шлях/до/Godot_v4.4.1 ./build.sh` → `build/godot-web/`
(шаблони експорту 4.4.1 мають бути встановлені; варіант без потоків — працює без спеціальних заголовків сервера).
`build/godot-web/play.html` — сторінка, що вантажить стиснуті `index.wasm.gz` і `index.pck.gz`.
